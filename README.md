# Perumal Raja — Professional Portfolio

A responsive, static portfolio website built with HTML, CSS and vanilla JavaScript. The supplied resume PDF is in `public/` and is linked for download.

## Preview locally
Open `index.html` in a browser.

## Deploy to Vercel (free)
1. Create a GitHub account at https://github.com/ and a new repository (for example `perumalraja-portfolio`).
2. Upload all files and folders from this project, keeping `index.html` at the repository root and the resume in `public/`.
3. Sign in at https://vercel.com/ with GitHub.
4. Select **Add New → Project**, import the repository, and click **Deploy**. No build command is required; this is a static HTML site.
5. Vercel will provide a public `*.vercel.app` URL. You can change the project name in Vercel project settings if the name is available.

## Before publishing
- Confirm the public contact details and resume are the versions you want to share.
- The portfolio includes a brief professional summary of your work and selected projects. Edit `index.html` to update any details.
- Do not add internal government data, credentials, or non-public project screenshots to the public site.
